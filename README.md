# Linketinder

Linketinder é uma plataforma de cadastro de candidatos e empresas, desenvolvida com **TypeScript**, **Vite**, **HTML/CSS** e **LocalStorage**.  
Os formulários possuem validação de dados com **Regex**.

- **Candidato**: nome, e-mail, CPF, telefone, LinkedIn e skills.  
- **Empresa**: CNPJ, nome, e-mail, CEP e skills.  
- Validação garante formato correto e evita campos vazios.

**Tecnologias:** TypeScript, Vite, HTML/CSS, Regex, LocalStorage
